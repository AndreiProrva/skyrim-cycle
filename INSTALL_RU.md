# Установка C3 Skyrim Cycle 0.1.25

## 1. Подготовка

1. Проверьте версию SkyrimSE.exe: свойства файла → Подробно → версия
   **1.7.104.0**. Требуется Steam-версия Skyrim SE/AE для Windows x64.
2. Установите **SKSE 2.3.1** с https://skse.silverlock.org/ по инструкции SKSE:
   загрузчик и DLL — рядом со SkyrimSE.exe, Scripts — в Data или отдельным модом MO2.
3. Установите **Address Library for SKSE Plugins**, All-in-one AE, v13:
   https://www.nexusmods.com/skyrimspecialedition/mods/32444.
4. При отсутствии среды выполнения установите Microsoft Visual C++ v14 x64:
   https://learn.microsoft.com/en-us/cpp/windows/latest-supported-vc-redist.
5. Создайте отдельный профиль MO2 и резервную копию сохранения. Для первой
   проверки удобно использовать минимальный список модов.

Не выбирайте зависимости только по названию «SE» или «AE»: важны точные номера
Skyrim и SKSE. Данная DLL не поддерживает другие версии.

## 2. Установка архива

В MO2 нажмите «Установить мод из архива», выберите `C3-Skyrim-Cycle-0.1.25.zip`,
подтвердите установку. В корне архива находятся ESP, meshes, textures, SKSE и
Sound — это содержимое Data, дополнительный уровень Data создавать не нужно.
Включите мод слева и `C3SkyrimCycle.esp` справа. Запускайте SKSE через MO2.

В Vortex установите тот же ZIP как обычный мод, включите ESP и выполните Deploy.
Запускайте SKSE с активным развёрнутым модом. MO2-профиль разработчика,
сама игра и сторонние зависимости в архив не включены.

При обновлении заменяйте старую версию целиком, а не смешивайте файлы разных
экспериментальных сборок. Сохраните свои INI отдельно при необходимости.

## 3. Как получить велосипед

Загрузите сохранение и выйдите на ровную открытую площадку. Откройте консоль
клавишей `~` (на русской клавиатуре обычно Ё), переключите ввод на английский.
Введите:

    help "C3 Cycle Bike" 4

Найдите строку **NPC_** с названием **C3 Cycle Bike** и запишите её восьмизначный
FormID. Например, если вывод показывает **07000800**, выполните:

    player.placeatme 07000800 1

**07 — только пример:** первые две цифры зависят от порядка загрузки вашего
ESP. Используйте именно ID из вашей консоли. Не используйте ID сохранённого
экземпляра с префиксом FF. Команда создаёт новый велосипед: достаточно одного.
Закройте консоль, подойдите к велосипеду и нажмите E.

Для теста из главного меню вместо вступления в повозке можно открыть консоль
и выполнить `coc Riverwood`, затем создать велосипед командами выше. Это
тестовый старт, он не обязателен для обычного сохранения.

## 4. Управление и показания

- W/S — движение, A/D — поворот, E — посадка/сход при стандартных назначениях.
- Shift — ускорение.
- Верхние клавиши 1–8 — передачи: 14, 18, 22, 26, 30, 34, 38, 42 км/ч.
- L (физическая Д на русской раскладке) — включение/выключение тёплой фары.
- HUD показывает текущие RPM игровой анимации, фактическую скорость,
  передачу, состояние фонаря и подсказки. Передачи меняют скорость движения;
  RPM при этом могут оставаться близкими. Скорость на склоне/при столкновении
  и с Shift может отличаться от обычной целевой скорости.

Физический датчик и программа CYCPLUS для этого релиза не нужны. Их показания
в данный мод пока не поступают. Отдельного EXE, Python и генерации анимаций
для установки готового мода не требуется.

## 5. Настройки

Файл `SKSE/Plugins/C3CycleAudio.ini`, раздел `[Audio]`:

    WheelSound=1
    WheelVolumePercent=20
    WheelReferenceRPM=60
    MuteBikeHorseSounds=1
    RememberedPlayerBikeRef=0

Громкость — 0–100; WheelSound=0 выключает звук велосипеда. Последнее поле
заполняется программой для подавления звука именно вашего велосипеда до
посадки; чужой FormID из другого сохранения переносить не нужно.
`SKSE/Plugins/C3CycleLight.ini`, `[Light]`, `ConeEnabled=1` включает конус;
значение 0 оставляет дополнительный точечный свет. L управляет фонарём.
Редактируйте настройки при закрытой игре. Не меняйте общую громкость игры
для устранения звука конкретного велосипеда.

## 6. Если не работает

- Велосипеда нет: проверьте ESP, затем создайте его через help/placeatme.
- Модель есть, HUD/управления нет: проверьте точные версии игры/SKSE,
  Address Library и наличие DLL/таблицы C3CyclePose.bin.
- Розовые детали: textures/skyrimcycle должны устанавливаться вместе с meshes.
- Вылет: сначала проверьте минимальный отдельный профиль и совместимость
  сторонних модов на анимации/скелеты/ездовых животных. Не удаляйте сохранение.
- Для обращения приложите версию игры/SKSE, список модов, шаги воспроизведения
  и `C3KeyboardMotion.log` из каталога SKSE внутри Documents/My Games/Skyrim Special Edition
  (Documents может быть перенаправлен в OneDrive). Уберите личные пути из лога.

Не заменяйте обычные horse_rider HKX или скелеты персонажа вручную: готовый
архив не требует таких изменений. При проблеме со старой экспериментальной
версией создайте отдельный чистый профиль для сравнения.

## 7. Удаление

Слезьте с велосипеда, выключите фонарь, сделайте отдельное сохранение и выйдите.
Отключите мод и ESP в менеджере. Для полного отката предпочтительно загрузить
сохранение, сделанное до установки: удаление ESP не гарантирует очистку уже
созданных объектов из сохранения. Обычные файлы Skyrim менять не требуется.
